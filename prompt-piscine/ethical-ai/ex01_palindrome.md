# Palindrome Challenge

## Step 1 — Type it in plain english
- declare function to receive a string
- declare variable to hold the reversed version of the string
- reverse the string
- compare the received string with the reversed string
- if not the same, it is not a palindrome

## Step 2 — Type it in psuedocode
Function is_palindrome(input_string):
	Declare reversed_string
	Set reversed_string = reverse of input_string
	if input_string equals reversed_string:
		Return true
	Else: 
		Return false
End Function
